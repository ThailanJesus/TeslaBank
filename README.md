# 💳 TeslaBank — O seu banco do futuro

O **TeslaBank** é uma landing page moderna e responsiva criada para representar um banco digital fictício.  
O projeto foi desenvolvido com foco em **HTML**, **CSS** e **design limpo**, simulando um site institucional de fintech, com seções informativas e foco na experiência do usuário.

---

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura do site  
- **CSS3** — estilização e layout responsivo  
- **Normalize.css** — para garantir consistência entre navegadores  
- **Bootstrap Icons** — ícones modernos e leves  
- **Google Fonts (DM Sans & Inter)** — tipografia profissional  

---

## 🧠 Conceitos aplicados

Durante o desenvolvimento do TeslaBank, foram praticados conceitos fundamentais de front-end:

- Estruturação semântica em HTML  
- Organização e reutilização de variáveis no CSS  
- Layouts responsivos com Flexbox  
- Uso de variáveis globais para cores, fontes e espaçamento  
- Criação de componentes visuais reutilizáveis (cards, botões, seções etc.)  
- Práticas de design consistentes inspiradas em fintechs reais
